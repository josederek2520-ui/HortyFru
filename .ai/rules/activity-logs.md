# Activity Logs

## Auditoría visible completamente en español
El historial de actividad nunca muestra directamente nombres de atributos, clases, rutas, métodos, motivos ni fechas técnicas. Traduzca esos datos en la capa de presentación, use fechas dd/mm/aaaa y mantenga intactos los valores internos almacenados. El filtro de módulos es un desplegable para poder crecer sin pestañas horizontales.
